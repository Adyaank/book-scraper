# Book Scraper

A Python script that scrapes all 1,000 book titles and prices from
books.toscrape.com and saves them to a CSV file.

## What it does
- Loops through all 50 pages of the catalogue
- Pulls the full title and price of every book
- Saves the results into book.csv

## Built with
- Python, requests, BeautifulSoup

## How to run
pip install requests beautifulsoup4
python scraper.py
